# 📚 Online Learning Platform (LMS)

A full-stack Learning Management System (LMS) built using the MERN stack that enables students to learn online through interactive courses, video lessons, quizzes, certificates, and progress tracking.

---

## 🚀 Features

### 👤 Authentication
- User Registration
- Login & Logout
- JWT Authentication
- Password Encryption using bcrypt

### 📚 Course Management
- Browse Courses
- Course Details
- Enroll in Courses

### 🎥 Video Learning
- Stream Video Lessons
- Track Lesson Completion

### 📝 Quiz System
- Multiple Choice Questions
- Instant Score Evaluation

### 📊 Progress Tracking
- Learning Progress
- Course Completion Percentage

### 📜 Certificate
- Download Course Completion Certificate

### ⭐ Reviews
- Rate Courses
- Add Reviews

### 👨‍🏫 Instructor Dashboard
- Create Courses
- Upload Lessons
- Manage Students

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Online-Learning-Platform.git
```

### Install Dependencies

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd server
npm install
```

### Run Backend

```bash
npm run dev
```

### Run Frontend

```bash
npm run dev
```
